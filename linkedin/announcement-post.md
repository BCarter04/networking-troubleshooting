**Caption:**

I got tired of hunting for the same network troubleshooting steps every time a ticket came in.

So I put together a clean, practical set of guides and PowerShell scripts for the most common problems:

→ No internet / basic connectivity  
→ DNS vs path issues  
→ DHCP / APIPA (169.254)  
→ Ports and firewalls  
→ Wi-Fi  
→ Slow or intermittent connections  

It includes:
- A simple decision tree so you know where to start
- Classic indicators (the ones that show up in interviews)
- Safe, read-only PowerShell scripts you can run immediately
- A one-command summary + ticket-ready report generator

Everything is self-contained, uses only built-in PowerShell, and is free under MIT.

If you do help-desk, junior admin, or just want a reliable reference for network issues, it might save you time.
