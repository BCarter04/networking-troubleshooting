# Carousel: 7 Classic Network Indicators

**Upload:** `carousel-indicators.pdf` as a Document post

**Caption**

Most network problems announce themselves with one of these signs.

Here are seven classic indicators every help-desk technician should recognize on sight, plus the first action to take. These also appear in interviews.

Swipe through, then grab the full checklist and matching scripts from the repository.

---

**Slide reference**

1. Cover — 7 Classic Network Indicators
2. 169.254.x.x — DHCP failed (APIPA)
3. Valid IP, no gateway — Cannot leave the subnet
4. Ping by IP works, name fails — DNS problem
5. Ping gateway fails — Local Layer 2/3 issue
6. Yellow triangle — Limited or no internet
7. One port fails — Service down or firewall
8. Weak Wi-Fi signal — Distance, interference, or driver
9. Call to action — Full checklist and scripts
