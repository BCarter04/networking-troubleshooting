**Caption**

I kept looking up the same network troubleshooting steps.

So I put the most common ones into a single, practical repository:

- No internet / basic connectivity
- DNS versus path problems
- DHCP and APIPA (169.254)
- Ports and firewalls
- Wi-Fi
- Slow or intermittent connections

It includes a decision tree, classic indicators that appear in interviews, and safe PowerShell scripts you can run immediately. Everything uses only built-in PowerShell and is free under MIT.

If you do help-desk or junior admin work, it may save you time.
